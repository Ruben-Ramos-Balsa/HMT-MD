Verificación de la biblioteca

Estos controles comprueban que los archivos recibidos coinciden con la distribución. La consulta de los PDF no requiere ejecutarlos.

macOS y Windows

Se requiere Python 3. Abra esta carpeta en Finder o en el Explorador de archivos y ejecute COMPROBAR_MAC.command o COMPROBAR_WINDOWS.cmd. También puede utilizar la terminal, desde la carpeta principal:

macOS / Linux: python3 -I -B -S 06_VERIFICACION/verificar_integridad.py
Windows:       py -3 -I -B -S 06_VERIFICACION\verificar_integridad.py

La salida correcta es PASS_LIBRARY_FILES, con cero errores. La comprobación es de archivos; no vuelve a ejecutar las pruebas científicas.

Para evitar límites de rutas en instalaciones Windows, extraiga directamente en la raíz del USB o de C:, sin añadir otra carpeta envolvente. Puede abreviar el nombre de la carpeta a HMT; los enlaces seguirán funcionando.

English · Français

Python 3 is required for file verification, not for reading PDFs. Run the platform launcher in this folder or use the commands above from the library root. A successful check reports PASS_LIBRARY_FILES. Scientific runtime requirements are listed separately under Reproduction.
