## Conservación y reproducción documental

El [manifiesto](</Users/ruben/Documents/New project/output/INVENTARIO_GENEALOGICO_HMT_20260919/MANIFIESTO_REV01.json>) registra las huellas, los IDs de ficha y los controles de ensamblaje. El script `tools/reunir_inventario.py` no sobrescribe una revisión distinta: una ampliación requiere otro número de revisión. La igualdad literal de las piezas es un control documental, no una prueba de completitud matemática.

El directorio `censo` conserva rutas, huellas y localizadores candidatos de las raíces examinadas. Los JSONL están comprimidos sin pérdida. Las copias, traducciones y versiones históricas se conservan como procedencias distintas; no se contabilizan automáticamente como resultados distintos. El [resumen del censo](</Users/ruben/Documents/New project/output/INVENTARIO_GENEALOGICO_HMT_20260919/censo/RESUMEN.json>) declara su alcance.

## Iteración siguiente

El siguiente nivel será el subinventario: cada ficha general se descompone en pasos individualizados, con IDs derivados, cálculo intermedio, ejemplo, prueba, localizador y vínculo con las fichas que dependen de ella. El primer tramo comprende alfabeto 1–9, ejes, tabla bruta, ambas hojas, raíz digital, cocientes, módulo 1000 y rutas 3/6/9. La comparación de estas operaciones se hará con sus mapas concretos, sin suponer que sean intercambiables.

Se mantienen simultáneamente el cotejo de las diez introducciones, el reservorio y las fuentes extensas, y el registro de las incorporaciones pendientes a I, IX, X y los destinos sectoriales. No se inicia todavía la redacción de otro PDF.
