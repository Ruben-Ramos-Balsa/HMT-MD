3. Registro enriquecido y torres de 05. Las firmas nominales del
   suplemento E3 están declaradas; su payload no equivale al constructor

   generación completa. En 08 se desarrollan la consecuencia de Reynolds
   y los singletes, no todo el propietario de la génesis de SU(3).

   cuando se use el intercambio bariónico. 03 contiene holonomía/espín;
   las pruebas de Fock/CAR del antecedente V deben incorporarse si se
   anuncia su derivación en VI.
6. Ecuaciones de coherencia de los códigos topológicos, si VI anuncia
   toda la construcción categórica. 08 conserva reglas y matrices y
   prueba identidades elementales de unitariedad/bilinealidad, pero no
   sustituye una prueba de todos los pentágonos y hexágonos por esas
   comprobaciones.
7. Operador de canales, dominio del resolvente y continuación meromorfa
   de cada resonancia concreta. La fórmula general de Feshbach no
   demuestra existencia universal de polos.

08 incorpora directamente el criterio espectral más preciso del integral:
`(M−mI)P=0` caracteriza una línea, mientras que `PMP=mP` sólo basta si
se añade el carácter reductor. El ejemplo `diag(1,3)` y el vector

### Reproducción de los controles matemáticos finitos

El siguiente programa usa sólo aritmética entera y los registros publicados.
No genera constantes ni abre una tabla externa. Puede ejecutarse con
`python3 -I -S` sobre una copia de este bloque:

```python
def sg(n):
    return (n > 0) - (n < 0)

sigma12 = [1, 1, 1, -1, -1, -1] * 2

def F0(n, e):
    t = list(map(sg, e))
    return (
        n,
        sum(e),
        sum(sigma12[i] for i in range(12) if t[i] == 0),
        sum(sg(e[a] + e[a+4] + e[a+8]) for a in range(4)),
        sum(t[m] * t[(m+3) % 12] for m in range(12)),
    )

a = [5, 4, 4, -4, -4, -6] * 2
b = [4, 5, 4, -4, -6, -4] * 2
c = [1, 4, 1, -2, -4, -3] * 2
assert F0(8, a) == F0(8, b) == (8, -2, 0, 0, -12)
assert F0(28, c) == (28, -6, 0, -4, -12)
assert F0(36, [x+y for x, y in zip(a, c)]) == (36, -8, 0, 0, -12)
assert F0(36, [x+y for x, y in zip(b, c)]) == (36, -8, 0, -2, -12)

Q = {a: [] for a in range(3)}
for r in range(1, 10):
    for c in range(1, 10):
        if r % 2 == 0:
            Q[(r-c) % 3].append((r, c))
assert [len(v) for v in Q.values()] == [12, 12, 12]
assert sum(len(v)**2 for v in Q.values()) == 432
assert len(Q[0]) * len(Q[1]) * len(Q[2]) == 1728
assert 2 * (8*4 + 16*8) == 320
assert 2 * ((2*0 + 1*1 + 1*1) + (4*2 + 4*2 + 4*2)) == 52

rows = {

    'kpm': (54, -1, 17, -2, 2), 'k0': (54, 0, 32, 3, -2),
```
