# HMT — Holonomía Mathieu del campo de estrellas de Witt

## Resultados verificados

- Para cada 4-cara \(B\subset[12]\), la involución \(\sigma_B\) fija \(B\) y transpone los cuatro pares de \(\mu_W(B)\).
- Las 495 involuciones \(\sigma_B\) preservan \(W_{12}\).
- El grupo generado por ellas tiene orden \(95040\).
- Por tanto, generan \(M_{12}\).
- Para \(B_C=\{4,6,9,10\}\), \(\sigma_{B_C}=(1\,3)(2\,11)(5\,7)(8\,12)\).
- La configuración \((H_\alpha,H_e,H_\varphi,H_{\rm APP})\) tiene estabilizador trivial en \(M_{12}\).

## Interpretación

HMT no sólo selecciona una hexada. Selecciona una estrella polarizada dentro de un campo local de emparejamientos cuya holonomía global genera \(M_{12}\). La configuración HMT elimina todo gauge residual de esa simetría.

La frase central:

\[
\alpha
\text{ es el lift archimedeano del pétalo negativo de una estrella de Witt cuya 4-cara nuclear es la corona }729\text{ del corrector.}
\]

Y la frase estructural:

\[
\text{las estrellas locales de Witt generan }M_{12},\text{ y el marco HMT rigidifica ese }M_{12}.
\]
