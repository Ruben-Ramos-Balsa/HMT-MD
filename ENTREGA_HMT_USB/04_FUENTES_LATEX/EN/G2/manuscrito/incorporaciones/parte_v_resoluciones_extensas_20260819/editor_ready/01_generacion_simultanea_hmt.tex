\section{Unitary typing of the consumed object}

The preceding frozen block is not added to a graphical constructor of five
components. It replaces it. For each depth \(k\), let
\(\mathcal E_k\) be the APP--TRIT--TPK state enriched with all its surviving
emissions, and let \(\mathcal Z_k\) be the codomain of the unique correlative
action. The governing arrow is
\begin{equation}\label{eq:pdf2-constructor-unico-operaciones}
 \mathcal O_k:\mathcal E_k\longrightarrow\mathcal Z_k,
 \qquad
 \widehat x_k\longmapsto
 \mathcal O\bigl(\{\mathfrak e_\alpha:
 \alpha\in\operatorname{Ch}_k(\widehat x_k)\}\bigr).
\end{equation}
Its value simultaneously preserves the coordinates
\(\mathrm{sp},\mathrm{sol},\mathrm{gau},\mathrm{coh},\mathrm{det}\)
of the same state and the same ledger. It is not a tuple of independent
factors nor the tautological graph of five previously separated maps.

The truncations of the state and of the action are written
\[
 u^{\mathfrak e}_{\ell,k}:\mathcal E_\ell\to\mathcal E_k,
 \qquad
 u^{\mathcal O}_{\ell,k}:\mathcal Z_\ell\to\mathcal Z_k,
 \qquad \ell\ge k,
\]
and satisfy a single naturalness,
\begin{equation}\label{eq:pdf2-naturalidad-accion-unica}
 u^{\mathcal O}_{\ell,k}\circ\mathcal O_\ell
 =\mathcal O_k\circ u^{\mathfrak e}_{\ell,k}.
\end{equation}
Therefore, the action passes to the limit without selecting a history:
\[
 \mathcal O_\infty:
 \mathcal C_{\rm cont}^{\rm disc}:=\varprojlim_k\mathcal E_k
 \longrightarrow
 \mathcal Z_\infty:=\varprojlim_k\mathcal Z_k.
\]
The notations used in the five chapters are viewed intrinsically of that
single value:
\begin{equation}\label{eq:pdf2-operacion-infinita-tipificada}
 \mathfrak G_T^{\rm int}
 :=\operatorname{View}_T\!\left(
 \mathcal O_\infty(\mathcal C_{\rm cont}^{\rm disc})\right),
 \qquad
 T\in\{\mathrm{sp},\mathrm{sol},\mathrm{gau},\mathrm{coh},\mathrm{det}\}.
\end{equation}
Here \(\operatorname{View}_T\) merely exposes the coordinates required by an
application; it does not create a branch, a factor, a subdomain, or a selector. The
starting structure of every resolution is always the complete value of
\(\mathcal O_\infty\), with the other four characteristics present.

\begin{falsifier}[Causal order and non-disaggregation]
The junction fails if \(\mathbb R\) or the continuum is used as input to
\(\mathcal O_k\), if \(\mathcal O_k\) is replaced by five independent
constructors, if a single terminal history is selected or if a view
\(\operatorname{View}_T\) is confused with the complete object. In any
of these cases the conclusion of the application chapter ceases to transfer.
\end{falsifier}
